# 🌐 Responsive Personal Portfolio Website

A modern, responsive and interactive personal portfolio website developed using **HTML5, CSS3 and JavaScript**.

The website showcases my profile, technical skills, projects, internships, education, certificates, blog articles and contact information through a clean and professional interface.

---

Hi, I'm **Rutuja Nighot**, an MCA student interested in **Web Development, Data Analytics, Python and Software Development**.

## 🎯 Project Objective

The main objective of this project is to develop a professional personal portfolio website that:

- Presents my professional profile
- Showcases my technical skills
- Displays my projects
- Highlights education and internship experience
- Presents certificates and achievements
- Provides a blog section

## ⚙️ How to Run

### Step 1

Download or copy all project files into one folder.

### Step 2

Open the project folder in Visual Studio Code.

### Step 3

Make sure the following files are present:

```text

script.js
resume.pdf
README.md
```

### Step 4

Open `index.html` in a web browser.

You can also use **Live Server** in Visual Studio Code.
